Using your phone? Start with Codespaces
  1. Open the Kira repository in your phone browser. Choose Code → Codespaces → Create codespace. Use Desktop site if needed.
  2. Follow the installation and Pages instructions in the README.
  3. Start the Python backend, copy its access token, then forward port 3000 as Public. Only do this with the token protection enabled.
  4. Paste the forwarded HTTPS address and token above. The backend must allow your Pages origin.

Codespaces requires an available quota or billing allowance. Sleeping/stopped Codespaces cannot generate or train.

Train your Kira

Train a small, real text Transformer from scratch. A short run proves the pipeline works; it will not create a useful assistant. Chat history is never added automatically.

2 layers · width 64 · 4 query / 2 KV heads · SwiGLU · AdamW. At least two distinct documents are required. The validation split is held out before tokenizer training. Web uploads are limited to 32 KiB; use Python for larger datasets and models.
