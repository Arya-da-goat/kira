1. Multimodal Tokenizer & Input Fusion (Astra Core)

Byte-Pair Encoding (BPE / TikToken) mapping language text, vision patch tokens ($\mathbf{z}_{\text{vision}}$), and audio spectrogram frames into a unified stream with ChatML special tokens: <|im_start|>, <|im_end|>, <|thought|>.

↓
2. Rotary Position Embeddings (RoPE)

Applies complex 2D orthogonal rotations to Query and Key projections with frequency base $\theta_i = 10000^{-2i/d}$, guaranteeing relative distance invariance across arbitrarily long context windows:

R_{θ, m}^d = diag(R_{θ_1, m}, ..., R_{θ_{d/2}, m})
↓
3. Root Mean Square Pre-Normalization (RMSNorm)

Fast, stable layer normalization without mean-centering overhead applied before each sub-layer:

RMSNorm(x) = (x / √(mean(x²) + ε)) ⊙ γ
↓
4. Grouped-Query Attention (GQA) & KV-Cache

Reduces memory bandwidth by sharing $H_{kv}$ key-value heads across $H_q$ query heads. Integrates an $\mathcal{O}(1)$ Key-Value (KV) cache for instant token generation, causal triangular masking, and soft-capped attention logits (cap = 30.0):

Attention(Q, K, V) = Softmax( 30 · tanh( (Q · K^T / √d_k) / 30 ) ) · V
↓
5. Sparse Mixture of Experts (MoE) with SwiGLU

Dynamic router gating network distributing tokens to the Top-2 most specialized experts out of 8 domain-specific SwiGLU networks (Syntax, Math, Code, Astra Multimodal, Creative Dialogue, STEM Physics, CoT Reasoning, Safety Alignment):

SwiGLU(x) = (x · W_gate ⊙ SiLU(x · W_gate)) (x · W_up) · W_down
↓
6. Chain-of-Thought (CoT) Reasoning Engine

Internal multi-step hypothesis formulation, intermediate scratchpad generation, and logical validation inside <|thought|> blocks prior to user emission.

↓
7. Final RMSNorm + Unembedded LM Head + LoRA

Vocabulary projection with Low-Rank Adaptation ($\Delta W = \frac{\alpha}{r} B A$) and adaptive nucleus (Top-P) / temperature autoregressive decoding.
